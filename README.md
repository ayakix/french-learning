# french-learning

ゼロからフランス語を **AIだけ** で学び、DELF B2 を目指す実験の記録です（Learning in public）。

- 教材は書籍を購入せず、すべて AI（LLM / TTS）で生成する
- 体系性は CEFR / DELF の公式な能力記述を骨組みとして確保する
- 客観的な評価のために、DELF 試験だけは外部で受験する
- ネイティブ向けのコンテンツ（ポッドキャスト、YouTube、音楽、映画など）は、学習教材ではないのでインプットとして使ってよい

## マイルストーン

| 時期 | 目標 |
|---|---|
| 2026-10-01 | 学習開始（フランス語の知識ゼロ） |
| 2027-03 | DELF A1 受験 |
| 2028 頃 | DELF B2 |

学習時間の目安は 1 日 1 時間。

## ディレクトリ構成

```
curriculum/   学習の骨組み（CEFR/DELF の能力記述をもとに AI で生成）
materials/    AI が生成した教材（例文・会話スクリプト。音声は git 管理外）
journal/      日々の学習記録（時間・内容・振り返り）
mistakes/     間違いノート
apps/web/     学習用 Web アプリ
scripts/      TTS 生成などの CLI ツール
```

## 使っている AI

- Claude Code：学習のメイン（教材生成・添削・記録）
- ElevenLabs：TTS（音読手本、シャドーイング）
- Gemini：会話練習
