# 00-5 子音と読まない文字

目標：語末の子音を読むか判断できる。c / g / s の読み分けができる。フランス語の r を発音できる。

## 1. 語末の子音は基本的に読まない

| フランス語 | 意味 | 発音 |
|---|---|---|
| petit | 小さい | [pəti] |
| grand | 大きい | [ɡʁɑ̃] |
| trop | 〜すぎる | [tʁo] |
| vous | あなた | [vu] |
| nez | 鼻 | [ne] |

### 例外：c / r / f / l は読むことが多い

英単語 **CaReFuL**（注意深い）の子音、と覚える。

| フランス語 | 意味 | 発音 |
|---|---|---|
| avec | 〜と一緒に | [avɛk] |
| bonjour | こんにちは | [bɔ̃ʒuʁ] |
| neuf | 9 | [nœf] |
| hôtel | ホテル | [otɛl] |

ただし、**-er で終わる単語の r は読まない**ことが多い（動詞の不定形 parler [paʁle] など）。

### 語末の e が子音を「起こす」

語末の e 自体は読まないが、その前の子音は読むようになる。**形容詞の男性形・女性形の区別**に直結する。

| 男性形 | 女性形 |
|---|---|
| petit [pəti] | petite [pətit] |
| grand [ɡʁɑ̃] | grande [ɡʁɑ̃d] |
| français [fʁɑ̃sɛ] | française [fʁɑ̃sɛz] |

## 2. h は読まない

h は常に発音しない。

- hôtel [otɛl]、homme [ɔm]（男・人）、heure [œʁ]（時間）

## 3. c と g は後ろの文字で読み方が変わる

| 綴り | 音 | 例 |
|---|---|---|
| c + a / o / u | [k] | café, comme, cuisine |
| c + e / i / y | [s] | ce, ici, cinéma |
| ç + a / o / u | [s] | ça, garçon |
| g + a / o / u | [ɡ] | gare, gomme |
| g + e / i / y | [ʒ] | âge, girafe |
| gu + e / i | [ɡ] | guitare |

## 4. s は母音にはさまれると [z]

| フランス語 | 意味 | 発音 |
|---|---|---|
| poisson | 魚 | [pwasɔ̃] |
| poison | 毒 | [pwazɔ̃] |
| dessert | デザート | [desɛʁ] |
| désert | 砂漠 | [dezɛʁ] |
| maison | 家 | [mɛzɔ̃] |

ss は [s]、母音にはさまれた s は [z]。間違えると「魚」が「毒」になる。

## 5. 2 文字で 1 つの音

| 綴り | 音 | 例 |
|---|---|---|
| ch | [ʃ] | chat, chocolat |
| ph | [f] | photo |
| qu | [k] | qui, quatre |
| th | [t] | thé |
| gn | [ɲ] | montagne, champagne |
| -tion | [sjɔ̃] | nation, attention |
| ill | [j] | fille [fij], famille [famij] |

ill の例外：ville [vil]（町）、mille [mil]（千）は [l] で読む。

## 6. フランス語の r [ʁ]

舌先は使わず、**喉の奥（のどちんこのあたり）を軽く震わせる**。うがいをするときの音に近い。

練習の順番：

1. 「ハ」と強く息を出す
2. その「ハ」を喉の奥で少しこすれるように出す
3. 母音をつける：ra, ri, rou

| フランス語 | 意味 | 発音 |
|---|---|---|
| rouge | 赤い | [ʁuʒ] |
| Paris | パリ | [paʁi] |
| merci | ありがとう | [mɛʁsi] |
| très | とても | [tʁɛ] |

## 聞いてまねする

上の各表の単語をすべて対象とする。特に次の組み合わせは続けて聞き比べる。

| フランス語 | 意味 | 発音 | ポイント |
|---|---|---|---|
| petit | 小さい（男性形） | [pəti] | t を読まない |
| petite | 小さい（女性形） | [pətit] | t を読む |
| poisson | 魚 | [pwasɔ̃] | [s] |
| poison | 毒 | [pwazɔ̃] | [z] |
| fille | 娘 | [fij] | ill は [j] |
| ville | 町 | [vil] | 例外で [l] |

## 練習

### 読み方の予想

自分で読んでから、Claude に再生してもらって確認する。

1. sac（鞄）
2. chanter（歌う）
3. garage（ガレージ）
4. rose（バラ）
5. cuisine（台所）
6. gentil（親切な）

<details>
<summary>答え</summary>

1. [sak]：語末の c は読む（CaReFuL）
2. [ʃɑ̃te]：ch は [ʃ]、-er の r は読まない
3. [ɡaʁaʒ]：1 つ目の g は a の前で [ɡ]、2 つ目は e の前で [ʒ]
4. [ʁoz]：母音にはさまれた s は [z]
5. [kɥizin]：c は u の前で [k]
6. [ʒɑ̃ti]：g は e の前で [ʒ]、語末の l は例外的に読まない
