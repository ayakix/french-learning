# 00-3 複数の文字で 1 つの音を表す綴り

目標：ai, au, eau, eu, oi などを見たら、すぐに 1 つの音として読める。

## ルール

フランス語では、母音字の組み合わせを 1 つの音で読む。ローマ字読みで「ア・イ」と分けて読まないこと。

| 綴り | 音 | 例 |
|---|---|---|
| ou | [u] | vous, rouge |
| ai, ei | [ɛ] | lait, neige |
| au, eau | [o] | auto, beau, eau |
| eu, œu | [ø] または [œ] | deux, bleu / peur, sœur |
| oi | [wa] | moi, trois |

### eu の 2 つの音

- [ø]：唇を丸めて「エ」と言う。単語の最後など、後ろに発音する子音がないとき（deux, bleu）
- [œ]：[ø] より口を開ける。後ろに発音する子音があるとき（peur, fleur）

A1 の段階では、2 つを厳密に区別できなくても通じる。「唇を丸めた『エ』」と覚えておけばよい。

## 練習

### 1. 読んでみる

Claude に再生してもらう前に、まず自分で読んでみる。その後に再生してもらって答え合わせをする。

1. jaune（黄色い）
2. chaise（椅子）
3. toi（君）
4. cheveux（髪）
5. bateau（船）

<details>
<summary>答え</summary>

1. [ʒon]：au は [o]、語末の e は読まない
2. [ʃɛz]：ai は [ɛ]、s は母音にはさまれて [z]、ch は [ʃ]（00-5 で扱う）
3. [twa]：oi は [wa]
4. [ʃəvø]：eu は [ø]、語末の x は読まない
5. [bato]：eau は [o]

</details>
