# 単元 00：発音と綴り

目標：綴りを見て読める。聞いて綴りが想像できる。（想定 10 時間）

## この単元の決まりごと

- `[ ]` の中は発音記号（IPA：国際音声記号）。辞書にも載っている表記なので、最初から慣れておく
- カタカナで読み方は書かない。カタカナに置き換えると日本語の音で覚えてしまうため
- 各回の表の 1 列目（フランス語）は音声化の対象。今は macOS の `say`（Thomas）で再生し、ElevenLabs 契約後に作り直す

## 進め方

1. 説明を読む
2. 「聞いてまねする」の単語を Claude に再生してもらい、声に出してまねする
3. 練習問題を解く（答えは折りたたみの中）
4. 間違えたものを journal と `mistakes/` に記録する
