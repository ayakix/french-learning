# 00-2 母音の基本

目標：日本語の「アイウエオ」にない母音を区別できる。特に u [y] と ou [u]。

## なぜ母音が大事か

日本語の母音は 5 つだが、フランス語には（鼻母音を除いて）10 以上ある。母音を区別できないと、別の単語に聞こえてしまう。
例：tu [ty]（君）と tout [tu]（全部）は、母音だけが違う。

## 主な母音

| 音 | 主な綴り | 口の形 | 例 |
|---|---|---|---|
| [a] | a | 日本語の「ア」とほぼ同じ | papa, la |
| [i] | i, y | 日本語の「イ」より口を強く横に引く | ici, stylo |
| [y] | u | **唇を「ウ」の形に丸めたまま「イ」と言う** | tu, rue |
| [u] | ou | 唇を強く丸めて突き出す。日本語の「ウ」より奥 | vous, roue |
| [e] | é, -er, -ez | 口を横に引いた「エ」 | été, parler, nez |
| [ɛ] | è, ê, e＋子音 2 つ | 口を縦に開けた「エ」 | mère, fête, merci |
| [o] | o（語末）, ô | 唇を丸めた「オ」 | mot, rôle |
| [ɔ] | o（子音の前） | 口を開けた「オ」 | porte, école |
| [ə] | e（アクセントなし） | 力を抜いた弱い音。省略されることも多い | le, de, je |

## 最重要：u [y] と ou [u]

日本人が一番苦労する区別。練習方法：

1. 「イー」と言う
2. 舌の位置を変えずに、唇だけを「ウ」の形に丸めて突き出す
3. その音が [y]

| フランス語 | 意味 | 発音 |
|---|---|---|
| tu | 君 | [ty] |
| tout | 全部 | [tu] |
| rue | 通り | [ʁy] |
| roue | 車輪 | [ʁu] |
| vu | 見た（voir の過去分詞） | [vy] |
| vous | あなた | [vu] |
| dessus | 上に | [dəsy] |
| dessous | 下に | [dəsu] |

## アクセントのない e

アクセント記号のない e は、位置によって読み方が変わる。

| 位置 | 読み方 | 例 |
|---|---|---|
| 語末 | 読まない | table [tabl], France [fʁɑ̃s] |
| 1 音節の単語 | [ə] | le [lə], je [ʒə] |
| 子音 2 つの前 | [ɛ] | merci [mɛʁsi], elle [ɛl] |
| 単語の途中 | [ə] または省略 | samedi [samdi]（土曜日） |

## 聞いてまねする

| フランス語 | 意味 | 発音 | ポイント |
|---|---|---|---|
| papa | パパ | [papa] | |
| ici | ここ | [isi] | 口を強く横に引く |
| tu | 君 | [ty] | 唇を丸めて「イ」 |
| tout | 全部 | [tu] | 唇を突き出す |
| été | 夏 | [ete] | 2 つとも [e] |

| samedi | 土曜日 | [samdi] | 真ん中の e が消える |

## 練習

### 1. 聞き分け

Claude が再生する単語が、どちらかを答える。

1. tu / tout
2. rue / roue
3. vu / vous
4. dessus / dessous

（答えは再生した順番による。Claude が答え合わせをする）

### 2. 読み方の予想

次の単語の e は読むか、読まないか。読むならどの音か。

1. table
2. le
3. elle
4. petite（2 つ目の e）

<details>
<summary>答え</summary>

1. 読まない [tabl]
2. [ə] [lə]
3. [ɛ]（後ろに子音 2 つ）[ɛl]
4. 読まない [pətit]（1 つ目の e は [ə]）

</details>
