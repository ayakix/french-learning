# 00-6 リエゾン・アンシェヌマン・エリジオン

目標：単語と単語の音がつながるルールを知る。つながった音を聞いて、元の単語に分解できる。

## なぜ大事か

フランス語は単語ごとに区切らず、**つなげて発音する**。ルールを知らないと、知っている単語でも聞き取れない。
例：les amis は「レ・アミ」ではなく [le.za.mi] と聞こえる。

## 1. アンシェヌマン（enchaînement）

もともと読む語末の子音が、次の単語の母音とつながる。

| フランス語 | 意味 | 発音 |
|---|---|---|
| il est | 彼は〜だ | [i.lɛ] |
| elle aime | 彼女は好きだ | [ɛ.lɛm] |
| avec elle | 彼女と一緒に | [a.vɛ.kɛl] |

## 2. リエゾン（liaison）

**普段は読まない**語末の子音が、次の単語が母音（または読まない h）で始まるときに読まれる。

| 綴り | つながるときの音 | 例 |
|---|---|---|
| s, x | [z] | les amis [le.za.mi]、deux heures [dø.zœʁ] |
| t, d | [t] | petit ami [pə.ti.ta.mi]、quand il [kɑ̃.til] |
| n | [n] | un ami [œ̃.na.mi] |

### 必ずつなげる場合

- 冠詞・数詞＋名詞：les enfants、deux ans
- 代名詞＋動詞：vous avez、ils ont、nous aimons
- 名詞の前の形容詞＋名詞：petit enfant
- c'est の後：c'est un…

### つなげてはいけない場合

- et の後：un garçon et une fille（et と une はつなげない）
- 単数の名詞の後：un étudiant anglais（étudiant と anglais はつなげない）
- h aspiré（有音の h）の前：les héros [le.e.ʁo]

h aspiré は、読まない点では普通の h と同じだが、リエゾンやエリジオンを妨げる。どの単語がそうかは辞書で確認する（覚える数は多くない）。

### 最重要ペア

| フランス語 | 意味 | 発音 |
|---|---|---|
| ils sont | 彼らは〜だ（être） | [il.sɔ̃] |
| ils ont | 彼らは持っている（avoir） | [il.zɔ̃] |

[s] か [z] かだけで動詞が変わる。

## 3. エリジオン（élision）

母音で終わる短い単語が、次の母音（または読まない h）の前で母音を落とし、アポストロフィ（'）になる。**綴りも変わる**。

| 元の形 | エリジオン後 | 例 |
|---|---|---|
| le / la | l' | l'ami、l'école、l'homme |
| je | j' | j'aime |
| de | d' | d'accord |
| ne | n' | je n'aime pas |
| que | qu' | qu'est-ce que |
| ce | c' | c'est |
| si + il | s'il | s'il vous plaît |

## 聞いてまねする

| フランス語 | 意味 | 発音 | ポイント |
|---|---|---|---|
| les amis | 友だちたち | [le.za.mi] | s → [z] |
| vous avez | あなたは持っている | [vu.za.ve] | |
| deux heures | 2 時 | [dø.zœʁ] | x → [z]、h は読まない |
| un ami | 1 人の友だち | [œ̃.na.mi] | n がつながる |
| petit ami | 恋人（男性） | [pə.ti.ta.mi] | t がつながる |
| ils sont | 彼らは〜だ | [il.sɔ̃] | [s] |
| ils ont | 彼らは持っている | [il.zɔ̃] | [z] |
| il est | 彼は〜だ | [i.lɛ] | アンシェヌマン |
| l'homme | その男 | [lɔm] | エリジオン |
| les hommes | 男たち | [le.zɔm] | 普通の h なのでリエゾンする |
| les héros | 英雄たち | [le.e.ʁo] | h aspiré なのでリエゾンしない |
| c'est un ami | 友だちだ | [sɛ.tœ̃.na.mi] | 2 か所でつながる |
| s'il vous plaît | お願いします | [sil.vu.plɛ] | |
