## 間違えたこと・気づき

### フランス語

- E [ə]・G [ʒe]・J [ʒi]・I [i]・Q [ky]・U [y] など、英語の読み方につられやすい文字が多い。W（double vé）と Y（i grec）は名前の由来ごと覚える
- **G [ʒe] と J [ʒi] を聞き間違えた**。最初の音が同じで、最後の母音だけが違う（G は「エ」、J は「イ」で終わる）→ `mistakes/` に記録
- é と è は日本語の「エ」の両側にあるので、どちらも「エ」に聞こえる。é は「イ」寄り（唇を横に引く）、è は「ア」寄り（あごを下げる）
- ^ の多くは昔あった s の跡なので、英語から意味を推測できる（forêt ↔ forest、hôpital ↔ hospital）
- フランス語の accent は記号の名前で、強く読む場所ではない

### AI で学ぶことについて

- 「AI だけで学ぶ」と言っても、学習の順序（骨組み）は外部の体系に頼ったほうがよい。AI に丸投げすると体系性が崩れる
- AI が生成したフランス語に誤りがあっても、ゼロからの学習者には気づけない。別の AI（Gemini）でのクロスチェックを予定
- **TTS も読み間違える**：1 文字だけ渡すと、I をローマ数字の un、Z や M・N も別の読み方をした。文字の名前の綴りや、同じ発音の単語（M → aime、N → haine）で読ませて解決。最終確認は人間の耳が必要
- 「もう一度」と頼むたびに待ち時間があり、自分のペースで繰り返せる画面が欲しくなった → Web アプリの最初の要件になった
- Claude Code のプロンプト候補がクイズの答えを表示してしまった → このプロジェクトでは無効にした

### ツール

- ElevenLabs の画面に表示される「キー ID」は API キーではない。API キーは `sk_` で始まり、作成時に一度だけ表示される。また、キーには権限（TTS / Voices / Models / User）を個別に付ける必要がある
