| 2026-10-01 | 00-1 | 1 文字の聞き取り（gé） | J | G [ʒe] | G と J は最初の [ʒ] が同じで、最後の母音だけが違う。G は「エ」、J は「イ」で終わる。英語の G / J の読み方と逆に感じやすい |
| 2026-10-02 | 00-1 | 1 文字の聞き取り（té） | D | T [te] | フランス語の T は英語と違って息をほとんど出さない（帯気しない）ので、D に近く聞こえる。喉が震えるかどうか（日本語の「た」と「だ」の違い）で聞き分ける。P・K も同じ |
| 2026-10-02 | 00-1 | é か è かの聞き分け（prêt） | é | è [ɛ]：prêt [pʁɛ] | ê は è と同じ [ɛ]。pré [pʁe]（草原）とのペア。é は唇を横に引く「イ」寄り、è はあごを下げる「ア」寄り |
| 2026-10-02 | 00-1 | é か è かの聞き分け（fait） | é | è [ɛ]：fait [fɛ] | fée [fe]（妖精）とのペア。語末の é / è の区別はネイティブでも弱まっており、お手本の音声で違いが出ているかも要確認 |
| 2026-10-02 | 00-1 | é か è かの聞き分け（parlais） | é | è [ɛ]：parlais [paʁlɛ] | parlé [paʁle]（話した）とのペア。この日の é/è は 3 問とも、正解が è で回答が é だった（è が é に聞こえている） |
| 2026-10-03 | 00-2 | u か ou かの聞き分け（rue） | ou | u [y]：rue [ʁy] | roue [ʁu]（車輪）とのペア。[ʁ] がこもった音なので、続く母音まで「ウ」寄りに聞こえやすい。u [y] は唇を丸めたまま「イ」で、高く鋭く聞こえる |
